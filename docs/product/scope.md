# دامنه محصول (فاز اول)

> مرجع محدودیتها: [project-context](../engineering/project-context.md) (`C-1` .. `C-15`)
> ترتیب ساخت: [roadmap](roadmap.md) · سؤالهای باز: [open-questions](open-questions.md)

## محصول در یک جمله

پلتفرم آنلاین سفارش لباس چاپی سفارشی: کاربر در مرورگر خودش طرح را روی تیشرت میسازد، پیشنمایش
میبیند، آن را به یک محصول قابل فروش تبدیل میکند، لینکش را به اشتراک میگذارد و مشتری سفارش میدهد؛
سفارش پس از پرداخت (زرینپال) برای چاپ و ارسال ثبت میشود. همین محصول در دو حالت کار میکند:
**SaaS** (هر کاربر فروشگاه خودش را دارد) و **B2B** (سازمان با چند کاربر و فهرست قیمت اختصاصی).

## جریان اصلی کاربر (برگرفته از دموی مرجع، ۰۰:۰۰ تا ۰۳:۴۴)

1. **ورود** — با موبایل و کد یکبارمصرف.
2. **صفحه اصلی** — محصولات ویژه، دستهبندیها، فهرست طرحها.
3. **انتخاب محصول** — تیشرت (فاز اول)، بعداً هودی و سایر.
4. **استودیو طراحی** — افزودن تصویر، افزودن متن (فونت، ضخامت، رنگ)، جابجایی و مقیاس، رنگهای محصول،
   پیشنمایش روی ماکاپ، **تولید طرح با هوش مصنوعی (غیرفعال)**.
5. **ثبت طرح** — عنوان و توضیح، ذخیره بهعنوان لیستینگ (پیشنویس/منتشرشده).
6. **صفحه عمومی محصول** — لینک اشتراکی، انتخاب رنگ و اندازه، «همین حالا بخر».
7. **پرداخت** — اطلاعات خریدار و آدرس، پرداخت از طریق زرینپال، بازگشت و تأیید سفارش.
8. **سفارش** — صفحه تشکر، «سفارشهای من»، وضعیت سفارش، پیامک تأیید و تغییر وضعیت.

## داخل دامنه (فاز اول)

| قلمرو | شامل |
|---|---|
| طراحی | استودیو وانیلا، سند طراحی نسخهدار، آپلود تصویر، متن فارسی، رنگبندی، ماکاپ، خروجی چاپ |
| فروش | محصول، رنگ، اندازه، قیمت، صفحه عمومی، لینک اشتراکی |
| خرید | سفارش تکمحصولی، اطلاعات ارسال، پرداخت زرینپال، پیگیری |
| حساب | ثبتنام/ورود با OTP، پروفایل، طرحهای من، فروشگاه شخصی |
| اعلان | پیامک تراکنشی از صف (کاوهنگار) |
| مدیریت | پنل ادمین: محصول، سفارش، کاربر، مالی، تنظیمات، پرچمها |
| هوش مصنوعی | دکمه **غیرفعال** + درز آماده اتصال، بدون هیچ ارائهدهندهای در این مرحله |
| B2B | سازمان، چند کاربر، کاتالوگ خصوصی، فهرست قیمت، سفارش سازمانی — فاز ۶ |

## خارج از دامنه (بهصراحت)

- هر API هوش مصنوعی (فعلاً) — `C-12`
- اپلیکیشن موبایل نیتیو · PWA آفلاین (تا تصمیم شما)
- چندزبانه بودن یا زبان دوم — `C-1`
- فروش طرحهای دیجیتال (دانلود فایل) بهجای کالای چاپی
- انبارداری و مرجوعی کامل (مگر با تصمیم صریح شما در `O-13`)
- بازارگاه چندفروشندگی با تسویه خودکار و مالیات پیشرفته
- هر سرویس خارجی (CDN، فونت آنلاین، تحلیلگر، پرداخت خارجی) — `C-5`

## معیار موفقیت فاز اول (پیشنهادی برای تأیید شما)

1. یک کاربر واقعی از موبایل خودش، بدون کمک، یک طرح بسازد و سفارش دهد و پرداخت موفق شود.
2. خروجی چاپ با نمونه واقعی چاپ مطابقت داشته باشد (رنگ، مقیاس، جای قرارگیری).
3. هیچ مرحلهای از جریان بالا بدون حالت خطا/خالی/بارگذاری رها نشود.
4. نصب روی هاست اشتراکی، فقط با پنل، بدون خطا و با مستندات کافی برای تکرار همان نصب.
